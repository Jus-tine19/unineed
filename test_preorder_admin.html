Test: Adding Variants to Preorder Product

  1. Go to Admin > Products
  2. Click Edit on the "uniform" product (ID: 21)
  3. Check the "Pre-order / Made-to-order" checkbox
  4. Click "Add Variant Type" button
  5. Fill in:
    • Variant Type: Size
    • Value: Large
    • Price: 750.00
    • Stock column will be HIDDEN (not required)
  6. Click "Add Another Value" to add more sizes if you want
  7. Click "Update Product"
  8. Check if variants were saved successfully
Expected Behavior
  • ✓ Stock column is hidden when pre-order is checked
  • ✓ Variant Type, Value, and Price fields are visible and required
  • ✓ Stock field is optional and set to 0 automatically
  • ✓ Form submits successfully
  • ✓ Variants appear in database with stock_quantity = 0
  • ✓ Student can see product with variants in shop
  • ✓ Student can select variant and add to cart
  • ✓ Student can checkout without stock validation
